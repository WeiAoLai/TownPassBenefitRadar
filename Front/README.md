# 領得到

2026 臺北秋季程式設計節・城市通微服務大黑客松（數位平權 × 友善共融・**拿不到**）

不用先知道自己是不是低收入戶。輸入「跟誰住、去年報稅多少、有沒有房」，算出：

1. **每個補助把誰算進你的家**（同一個家，三種家庭）
2. 很可能符合／可能符合（還差哪件事）／不符合（差在哪）
3. 每月大約能領多少，以及跨方案的申請順序建議
4. 要帶什麼文件、去哪裡申請

目前涵蓋 11 項（臺北市 115 年度）：

| 補助 | 主管 | 金額 | 家庭範圍 |
|---|---|---|---|
| 300 億中央擴大租金補貼 | 中央 | 每月 3,000～8,000 元起，依加碼倍數 | 本人、配偶、未成年子女 |
| 低收入戶、中低收入戶 | 臺北市 | 身分 | 社會救助法第 5 條（含爸媽、子女） |
| 中低收入老人生活津貼 | 臺北市 | 每月 8,329 或 4,164 元 | 以長輩為中心 |
| 身心障礙者生活補助 | 臺北市 | 每月 4,049～9,485 元 | 以身障者為中心 |
| 國民年金老年基本保證年金 | 中央 | 每月 4,049 元 | 只看本人 |
| 特殊境遇家庭：子女生活津貼 | 臺北市 | 每名 15 歲以下子女每月 2,950 元 | 本人、子女（不算爸媽、配偶） |
| 特殊境遇家庭：緊急生活扶助 | 臺北市 | 一次 2～3 個月最低生活費 | 同上 |
| 育兒津貼（未滿 2 歲） | 中央 | 每月 5,000～7,000 元 | 不看收入 |
| 臺北市生育補助 | 臺北市 | 一次 4～5 萬元 | 不看收入 |
| 敬老卡、愛心卡 | 臺北市 | 每月 600 點 | 只看本人 |

老人津貼、身障補助、基本保證年金三者同一人只能擇一，系統會建議金額較高的一項。

老人津貼會替家裡每位 65 歲以上的長輩（你自己或爸媽）各算一次，而且**用長輩自己的角度圈家庭**：
你是爸爸的子女，所以你的收入會算進爸爸的審查，已婚的兄弟姊妹則可以請社工評估排除。
家裡資料只輸入一次，換角度由引擎自動處理（`anchorScope`）。身障生活補助同理，以身障者本人為中心（例如替有身障的孩子申請時，孩子的兄弟姊妹不算）。

## 結果頁

1. **最上方摘要**：可以申請幾項、每月合計約多少（擇一的補助只算建議的那項）。
2. **搜尋框與快速篩選**：輸入「租屋」「長輩」「身障」等關鍵字，只顯示相關補助。
3. **可以申請 → 還要確認 → 符合但建議擇一不用申請**：每張卡片寫清楚申請人是誰、每月多少、**申請後對家人的影響**（誰的資料會被調查、會不會影響家人的補助、能不能跟其他補助一起領）。
4. **收起來的區塊**：「為什麼每個補助把不同的家人算進來」（家庭範圍表）與「目前不符合」（每項附原因，點開看計算細節）。

擇一規則：同一人同時符合老人津貼和身障生活補助時，只能擇一（兩個發給辦法都有規定），系統建議金額較高的一項。

## 跟 2024 佳作（townpass2024-welfare）的差異

| | 2024 | 領得到 |
|---|---|---|
| 輸入 | 自己選身份（低收／中低收） | 只填事實，身份由系統算出 |
| 家庭 | 各看各的清單 | 每個方案套用它自己的家庭定義 |
| 結果 | 項目清單 | 三態判定、金額、差在哪、擇優順序 |
| 規則 | 2024 年一次性抓取 | 有版本號，每個數字附法源 |

## 設計原則

- **沒有模型、沒有後端、不上傳個資**：規則是 JSON，判斷是純計算，所以能裝台北通的手機都能跑。
- **聰明問**（`src/engine/nextQuestion.ts`）：只問「還不確定」的方案需要的欄位，依金額權重 ÷ 回答成本排序。示範人物小安只要 7 題。
- **區間計算**（`src/engine/range.ts`）：收入、存款用區間回答，跨過門檻才追問確切數字。
- **iOS 15 相容**：`vite.config.ts` 的 `build.target` 設到 `safari15`（台北通 iOS 最低支援版本）。

npm install

## 檔案

- `rules/params-115.json`：年度參數，每個值都有 `cite`，`verify: true` 表示待查證
- `rules/programs.json`：家庭定義說明、租補金額表與加碼表、申請清單
- `src/engine/household.ts`：依方案圈出「它認定的家庭」
- `src/engine/evaluate.ts`：三態判定、差在哪、金額、跨方案建議
- `src/bridge.ts`：台北通橋接（`userinfo` 預填年齡、`phone_call`、`open_link`）

## 待查證與簡化

- 租補多項加碼是否擇優適用（目前取最高倍數）
- 老人津貼以爸媽為申請人時，假設爸媽是夫妻；孫子女是否同住以「你是否跟長輩同住」推估
- 祖父母、兄弟姊妹的老人津貼或身障補助要以他們為主角另外試算
- 以配偶為申請人時，配偶自己的爸媽沒有輸入，未列入計算
- 身障中度以上視為沒有工作能力（不以基本工資推算收入）
- 設籍與實際居住臺北市、最近一年在國內超過 183 天、未公費安置：目前假設符合，未逐項詢問
